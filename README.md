# dsh-context-console

DeepSeek Harness Web 界面的浏览器插件，包含两个功能模块：

## 功能

### 侧边栏上下文仪表盘

左侧菜单「设置」上方的一块实时卡片：

- **上下文窗口** — 进度条 + 百分比，随占用率变色：<60% 蓝、60–85% 橙、≥85% 红
- **缓存命中** — 绿色进度条 + 百分比
- **余额 HUD** — 官方账户余额每 30 秒刷新，本地持久化（重启保留"上次"数值）
- **扣费特效** — 每次花费飘出红色数字；未命中占比 ≥40% 时触发「暴击」放大飘字
- **缓存连击** — 输入命中率 ≥80% 连击 +1，未命中打断；最高连击永久保存
- **花费称号** — 按累计花费解锁：白嫖党 → 小试牛刀 → 氪金学徒 → 挥金如土 → 烧钱大师 → 财神下凡
- **今日统计** — 未命中 / 命中 / 生成三类花费分别累计，跨天自动归零
- **悬停详情** — 磨砂浮层显示已用 / 总量、命中 / 未命中 / 写入及构成
- **窄栏模式** — 侧边栏折叠时显示圆环

### 灵动岛通知

顶部居中的胶囊通知，小球弹出后弹簧展开：

- **触发场景** — 任务完成 / 审批等待 / 后台任务完成；同一会话 30 秒冷却
- **弹出条件** — 仅窗口未聚焦时弹出；标签隐藏时同时发送桌面通知（需授权）
- **停留策略** — 审批类常驻，点击跳转会话；普通通知自动收回；隐藏期间保持展开
- **设置页** — 「设置 → 灵动岛」：总开关（本地持久化）、暴击特效开关、桌面通知授权、测试弹窗

> 安装与使用方法见 [INSTALL.md](INSTALL.md)。Windows 下一条命令：`.\install.ps1`，然后重启 DSH；或走官方命令 `dsh plugin --profile web add file:<plugin 目录>`（需 pnpm）。

## 文件说明

| 路径 | 说明 |
| --- | --- |
| `plugin/` | 插件本体：package.json、宿主桩、客户端 bundle |
| `install.ps1` | 一键安装（复制插件、建 junction、写组合注册；自动备份，可重复执行） |
| `uninstall.ps1` | 一键卸载（还原组合、删 junction；加 `-RemovePlugin` 连插件目录删除） |
| `INSTALL.md` | 安装教程 |

## 工作原理

- 插件目录 `~/.dsh/plugins/dsh-context-console` — 位于用户目录，升级免疫
- 通过 junction 链入 profile 的 node_modules，并在 `~/.dsh/profiles/web/cordis.patch.yml` 注册一行；插件已声明 `dsh.bundle`，也可直接用官方 `dsh plugin add` 安装（自动注册 bundle 层，无需手动改配置）
- 启动时 client-modules 扫描到插件，将 bundle 注入浏览器；客户端注册三个官方插槽：
  - `sidebar.footer.action` — 仪表盘（Cordis 按钮下方）
  - `shell.overlay` — 灵动岛
  - `settings.section` — 设置页

## 注意事项

- 在 `@deepseek-ai/dsh` 0.1.0-rc.6 上验证；官方升级后若插槽契约变化，插件需跟进（但不会被覆盖删除）
- 灵动岛默认仅在窗口未聚焦时弹出，同一会话 30 秒冷却
- 桌面通知需在设置页授权一次；拒绝后可在浏览器站点设置中重新允许
- 扣费金额为按 deepseek-chat 价格表的**估算**（未命中 ¥2/M、命中 ¥0.5/M、输出 ¥8/M），余额以官方接口为准
